# 通用 AI 小说项目工作台原型

这是一个带本地服务和 SQLite 持久化的小说项目工作台原型，面向通用小说项目管理，不绑定单本小说。它支持新建小说项目、导入大纲、自动拆章、管理角色出场进度、学习文风、章节完稿评分、Skill 管理、多模型路由和一致性审查。

## 文件

- `index.html`：单页后台原型入口
- `styles.css`：中文 SaaS 后台布局和视觉样式
- `app.js`：样例数据、导入解析、页面渲染和原型交互
- `server.js`：本地 HTTP 服务、状态保存 API、SQLite 记忆库
- `workbench.sqlite`：运行时自动生成的本地数据库，保存项目、章节、文风、模型配置和记忆片段；该文件已加入 `.gitignore`，不要提交 API Key 和个人创作数据

## 使用

启动本地服务：

```bash
node server.js
```

访问：

```text
http://127.0.0.1:4173
```

页面会从 CDN 加载 lucide 图标。直接打开 `index.html` 时可以预览界面，但不会连接 SQLite，刷新持久化请使用 `node server.js`。

## 已覆盖页面

- 项目库：新建项目、导入大纲创建、切换小说项目
- 项目首页：目标章数、覆盖章数、今日任务、健康度、最近评分
- 大纲中心：txt/md 文件导入、分卷结构、章节节点、伏笔追踪
- 章节目录与细纲：由粗纲范围自动拆成逐章目录，并为每章生成可写作细纲
- 角色进度：出场计划、实际出场、缺席风险、关系进展
- 章节写作台：章节列表、正文编辑器、本章粗纲、本章细纲、约 2200 字正文生成、完稿评分
- 文风学习：样章训练、生成约束、高频禁词扫描
- Skill 管理：题材模板、可发表暧昧尺度、去 AI 味、故事路线补强
- 模型配置：GPT、DeepSeek、Gemini、Claude 多供应商和任务路由
- 一致性审查：角色、伏笔、时间线、禁词、尺度和资料风险检查
- 轻量 RAG 记忆增强：SQLite 保存项目、章节、角色、文风和连续性摘要，章节生成前按项目与章节检索相关记忆片段并注入模型提示词
- 去 AI 味审查：禁止用场景物品清单凑字数，优先检查人物欲望、顾虑、选择、后果和物品堆叠问题
